## 执行约定

- 每个计划执行完毕后：把状态列改为「已完成」，并在 git 提交信息中标注计划编号
- 计划文档存放于 `docs/superpowers/plans/`，命名 `YYYY-MM-DD-plan-N-<topic>.md`
- 任何计划执行中发现与 spec 冲突：先改 spec 并记录决策，再改计划
- 新会话恢复上下文时：先读本文件，再读对应计划与 spec

## 关键决策速查（防上下文丢失）

- 词汇量累计口径：中级 3000 / 高级 +2000 / 专业级 +2000，去重总量 7000
- 熟悉度 5 档：陌生 / 模糊 / 认识 / 熟悉 / 牢记；新词默认「模糊」
- 间隔阶梯（每档答对 2 次升档）：陌生 10min+1d；模糊 2d+4d；认识 7d+15d；熟悉 1mo+3mo；牢记=毕业不再复习
- 调档 8 条规则见 spec §4.3：答对 2 次升 1 档；答错降 2 档 + 会话内重现；变档后从新档间隔 1 重走；可手动调档；当日必过；新词/错词次日强制复习；积压 >100 暂停新词（10→6→0）；周末积压 >75 提前消化未来 3 天
- 每日新词：中级 10；高级/专业级 6。平日 20-30 分钟，周末 10-15 分钟只复习
- 技术栈：Flutter 3.47.2 / Dart 3.13.2、melos monorepo、drift（SQLite）、Riverpod、just_audio、flutter_tts、flutter_local_notifications、in_app_purchase
- 无服务器；content.db 只读随包发布，user.db 是唯一备份对象
- 付费：试用 + 一次性买断；口语：纯跟读无评测；晋升：达标提示 + 可手动切换
